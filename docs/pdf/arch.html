Rules in code, not only in prompts
Agents broke prompt rules in testing (run 11: the Manager edited its own guard tool). Cost: more tooling; scope/automation rules are still partly prompt-level.
Pengawas is server logic, not another agent
Stalls came from the platform (model saturation, 429); recurring tasks run at most hourly. Cost: needs WorkBuddy's local debug port.
Dashboard for task-made items
Cards were not rendered inside task sessions (run 08) — the dashboard lives in the Manager chat's right panel.
Conformity statuses, no scores
Conform · Minor NC · Major NC · OFI · N/A — a number looks more certain than the evidence.
Evidence only from Data-Operation, byte-identical
Missing evidence becomes a clarification card ("Belum tersedia"), never a guess.
Separation of duties
The external Auditor issues and sends; the Manager never assesses.
