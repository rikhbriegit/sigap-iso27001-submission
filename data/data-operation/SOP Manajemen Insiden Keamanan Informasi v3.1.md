# SOP MANAJEMEN INSIDEN KEAMANAN INFORMASI - v3.1
**Kontrol**: A.5.24 | **Owner**: IT Security | **Klasifikasi**: Internal

- Kode: NDP-SOP-IS-024 | Efektif: 12 September 2026 | Disetujui: CISO

## Persiapan (bagian 3)
- Tim respons: penanggung jawab insiden (ITSO), teknisi IT Ops/Infra, komunikasi (Legal/HR), koordinator cabang Makassar (Yusuf Ramadhan).
- Daftar kontak darurat diperbarui tiap kuartal (salinan fisik di ruang NOC).
- Latihan tabletop minimal 1x per tahun (terakhir: 20 Agustus 2026, skenario ransomware - lihat file terpisah).

## Klasifikasi prioritas (bagian 4)
| Prioritas | Definisi | Target respons |
|---|---|---|
| P1 | Layanan kritis down / data banyak bocor | 30 menit, komite langsung |
| P2 | Sistem penting terganggu / insiden terkonfirmasi | 2 jam |
| P3 | Isu terisolasi, dampak terbatas | 1 hari kerja |
| P4 | Event kecil/anomali | 3 hari kerja |
