# PEDOMAN PEMBELAN DOKUMEN, EMAIL, DAN MEDIA - v1.2
**Kontrol**: A.5.13 | **Owner**: IT Security | **Klasifikasi**: Internal

- Kode: NDP-IS-STD-013 | Efektif: 1 Juli 2025 (revisi kecil Feb 2026)

## Pelabelan minimal
1. Dokumen elektronik: label klasifikasi pada header/footer (template resmi sudah memuat; pilih via add-in Office).
2. Email: sensitivity label bawaan Microsoft 365 aktif sejak Maret 2026 (Publik/Internal/Rahasia/Sangat dibatasi) - label wajib sebelum kirim eksternal.
3. Media fisik: stempel klasifikasi pada kover; dokumen cetak "Sangat dibatasi" wajib nomor salinan.
4. File besar berklasifikasi Rahasia ke pihak eksternal: tautan aman terproteksi (lihat SOP A.5.14), bukan lampiran langsung.

## Catatan audit
Spot check pelabelan Q3-2026: 96% dokumen baru sudah berlabel; 2 dokumen HR diperbaiki labelnya (lihat laporan A.5.36).
