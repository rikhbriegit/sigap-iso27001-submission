# DENAH & STANDAR PENATAAN KABEL RUANG SERVER - 2025
**Kontrol**: A.7.12 | **Owner**: Rina Kartika (IT Infra) | **Klasifikasi**: Internal

- Pembaruan terakhir: November 2025 (inspeksi ulang setelah penataan Rak C)

## Standar
1. Kabel data & kabel daya dipisah jalur (raised floor conduit terpisah); jarak minimal dari sumber interferensi listrik.
2. Semua ujung kabel BERLABEL dua sisi (label printer, kode patch panel); kabel tak terpakai dicabut saat inspeksi.
3. Kabel kritis (trunk antar-rak, uplink) dalam proteksi mekanis; jalur kabel keluar ruang server via conduit terkunci.
4. Patch panel terdokumentasi (denah port); perubahan kabel = tiket perubahan (A.8.32).
5. Inspeksi penataan: tahunan (terakhir Nov 2025: ditemukan 3 kabel tanpa label - langsung diberi label).

## Cabang Makassar
- Kabel ruang server cabang: conduit permukaan; panel terkunci; inspeksi Maret 2026 OK.
